---
description: （用户显式授权报告）把全部/指定 findings 汇总为一份 MD 审计报告
argument-hint: "[all | F-编号 | 漏洞类型]"
---

本命令即用户的报告授权。对 $ARGUMENTS（默认 all）生成 Markdown 汇总报告：

1. 读取 `audit-state/`：state.json（技术栈/覆盖度/轮次）、findings/ 指定档案、chains.md、pending.md。若存在 `audit-findings/<类别>.md`（分类技能模式产物）一并读入分流。
2. **通杀口径（硬性）**：独立通杀（findings/ 中标"通杀"的档案）单独计数，是总览表唯一清单；组合链不计数，只在对应根的详情里引用并标注"不计数"；素材链只进附录。头部明确分列：独立通杀 N / 组合链 K（不计数）/ 待验证 M。
3. 输出 `./audit-reports/审计报告-<系统名>-<日期>.md`，单文件汇总，固定结构：头部 → 总览表（仅独立通杀）→ 每洞详情（前端触发点、污点链、净化缺口、关键代码 ≤10 行、利用条件与危害、组合链引用）→ 附录A 链路资产 → 附录B 待验证清单 → 附录C 覆盖度说明。
4. 信息逐字来自 findings 档案，不新增推断；file:line 逐字核对。
5. 完成后展示报告全文。
